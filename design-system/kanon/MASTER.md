## 1. Что взято из черновика, а что нет

| Из `ui-ux-pro-max` | Решение | Почему |
|---|---|---|
| Палитра «оранжевый + зелёный» на сером `#1F2937` | Отклонено | Типовая «фитнес-палитра»; у Канона уже есть свои бронза и мрамор, а фон по ТЗ — настоящий чёрный |
| Шрифты Barlow Condensed / Barlow | Отклонено | Спортивный «плакатный» характер не подходит спокойному приложению про пропорции |
| Стиль «Vibrant & Block-based», scroll-reveal на GSAP | Отклонено | Лишняя библиотека и анимация ради анимации |
| Шкала отступов 4 / 8 / 16 / 24 / 32 / 48 | Принято | |
| Чек-лист: без эмодзи-иконок, зоны нажатия ≥ 44 px, контраст 4,5:1, видимый фокус, `prefers-reduced-motion` | Принято | |
| Анти-паттерн «нет геймификации» | Принято частично | Уровни и серия дней уже есть; мультяшных наград не добавляем |

## 2. Идея

Канон — это канон пропорций Поликлета. Приложение выглядит как **скульптура в тёмном зале музея**: чёрный фон, тёплый мрамор тела, бронза как единственный акцент.

Один собственный приём на всё приложение — **«лента»**: прогресс показывается делениями мерной ленты, а не кольцами и дугами. Лента — главный инструмент пользователя (он меряет обхваты), и она же отличает Канон от других трекеров.

| Принцип | Что значит на практике |
|---|---|
| Один экран — один вопрос | Первый экран отвечает на главное; формулы, оговорки и таблицы — под раскрывающимся «подробнее» |
| Скульптура — герой | 3D-модель стоит на чёрном без рамки и карточки; текст её не перекрывает |
| Смелость в одном месте | Акцент — только бронза и только там, где есть действие или прогресс. Остальное — оттенки мрамора |
| Честность видна | Пометки «приблизительно», «эвристика» остаются, но мелким спокойным текстом, не плашками-предупреждениями |
| Не клон | Не используем: маскотов, «стеклянную» плавающую навигацию, лососевый акцент, карточки с фото атлетов, кольца активности |

## 3. Цвет

Тёмная тема — основная. В коде используются только переменные, не «сырые» hex.

| Токен | Тёмная | Светлая | Назначение |
|---|---|---|---|
| `--bg` | `#000000` | `#f4f1ec` | Фон страницы (OLED-чёрный) |
| `--surface` | `#141312` | `#ffffff` | Карточка |
| `--surface-2` | `#1f1d1b` | `#efebe4` | Плитка внутри карточки, поле, неактивная кнопка |
| `--surface-3` | `#2b2825` | `#e3ddd3` | Нажатое состояние, выбранный сегмент |
| `--line` | `#2b2825` | `#ddd6cc` | Разделители внутри списков, деления ленты |
| `--text` | `#f2efe9` | `#1d1d1f` | Основной текст (мрамор) |
| `--muted` | `#a39e96` | `#66625c` | Подписи, пояснения |
| `--accent` | `#c9965b` | `#8a5c28` | Бронза: действие, прогресс, активная вкладка |
| `--accent-ink` | `#1a1408` | `#fff8ee` | Текст на бронзе |
| `--good` | `#5db796` | `#25744f` | Патина: в норме, сильная зона |
| `--warn` | `#e3b04b` | `#8a5f0c` | Внимание, превышение |
| `--bad` | `#e0705a` | `#a53d20` | Ошибка, отстающая зона |

Контраст измерен в браузере 13.11.2026 (WCAG, по вычисленным цветам). Тёмная тема: `--text` на `--surface` 16,2; `--muted` на `--surface` 7,0 и на `--surface-2` 6,3; `--accent` на `--bg` 8,0; `--accent-ink` на `--accent` 7,0; `--good` 7,7; `--warn` 9,3; `--bad` 5,9 (на `--surface-2` 5,3). Светлая тема: `--text` 16,8; `--muted` 6,1 (на `--surface-2` 5,1); `--accent` 5,8; `--accent-ink` на `--accent` 5,5; `--good`, `--warn`, `--bad` подобраны не ниже 4,5 на `--surface` и `--surface-2`. Цвет никогда не единственный признак: рядом всегда число или подпись.

## 4. Шрифты

| Роль | Шрифт | Где |
|---|---|---|
| Заголовок экрана, название уровня, логотип | **Forum** 400 | Только крупно (≥ 22 px), не больше одного-двух мест на экран |
| Весь остальной текст и все числа | Системный: SF Pro на iPhone, Segoe UI на Windows | Числа — с `font-variant-numeric: tabular-nums` |

- Forum: автор Денис Машаров, лицензия SIL OFL 1.1, кириллица есть. Подключён локально через `@fontsource/forum` (без запросов к Google, работает офлайн). Начертание одно, поэтому «жирный Forum» не используем.
- Системный шрифт выбран намеренно: на iPhone приложение ощущается родным и ничего не грузит.

| Токен | Размер / высота строки | Применение |
|---|---|---|
| `--fs-display` | 34 / 1,1 (Forum) | Заголовок экрана |
| `--fs-figure` | 40 / 1 (700) | Главное число экрана |
| `--fs-title` | 20 / 1,25 (650) | Заголовок карточки |
| `--fs-value` | 24 / 1,1 (650) | Число в плитке |
| `--fs-body` | 16 / 1,45 | Текст |
| `--fs-small` | 14 / 1,4 | Вторичный текст |
| `--fs-caption` | 12 / 1,35 | Подписи; мельче 12 px (кроме подписей вкладок 11 px) не используем |

Запрещено: подписи ЗАГЛАВНЫМИ буквами, цепочки через «·» длиннее двух элементов, моноширинный шрифт для чисел.

## 5. Отступы, радиусы, тени

| Токен | Значение | Применение |
|---|---|---|
| `--s1 … --s6` | 4 · 8 · 12 · 16 · 24 · 32 px | Шаг 4 px |
| Поля экрана | 16 px + safe-area | |
| Между карточками | 12 px; между смысловыми разделами — 24 px | |
| `--r-card` | 22 px | Карточка |
| `--r-tile` | 14 px | Плитка, поле ввода |
| `--r-ctl` | 12 px | Кнопка, сегмент |
| `--r-pill` | 999 px | Чип, лента |

Радиус уменьшается с вложенностью (карточка → плитка → элемент). Тени в тёмной теме не используются — глубину дают три ступени поверхности. У карточек нет рамки.

## 6. Компоненты

| Компонент | Правило |
|---|---|
| Лента (`Tape`) | 41 деление; каждое пятое выше. Заполненные — `--accent`, пустые — `--line`; при превышении цели — `--warn`. Над лентой всегда подпись и число «факт / цель» |
| Карточка | `--surface`, без рамки, отступ 16 px. Заголовок 20 px. Кликабельная целиком — со стрелкой справа |
| Сворачиваемая карточка | Для справочных таблиц и методик. Заголовок — строка 56 px со стрелкой |
| Плитка показателя | `--surface-2`, подпись 12 px сверху, число 24 px, пояснение 12 px |
| Кнопка | Высота 48 px (малая — 44 px). Главная — бронза; обычная — `--surface-2`; опасная — текст `--bad` |
| Строка-ссылка | Высота ≥ 60 px: иконка, заголовок, пояснение, стрелка |
| Сегменты | Высота 44 px; прокрутка по горизонтали, если не помещаются |
| Навигация | 5 вкладок, высота 56 px + safe-area; активная — бронза + подпись |
| Иконки | Только SVG из `icons.tsx`: сетка 24, линия 1,75, скруглённые концы, без заливки. Эмодзи и символы «✕ ⟲ ‹ ›» как иконки не используются |
| Пустое состояние | Одна фраза, что здесь появится, и одна кнопка действия |
| Загрузка | Скелетон по форме будущего содержимого, а не слово «Загрузка…» |
| Ошибка поля | Текст под полем, цвет `--bad`, введённое значение не стирается |

## 7. Движение

| Токен | Значение | Где |
|---|---|---|
| `--t-press` | 80 мс | Отклик на нажатие: меняется фон или прозрачность, размеры не меняются |
| `--t-move` | 220 мс, `cubic-bezier(.2,.8,.2,1)` | Шторка снизу, раскрытие, заполнение ленты |
| `--t-exit` | 160 мс | Закрытие (быстрее открытия) |

Анимация только в ответ на действие пользователя. Появления блоков при прокрутке нет. При `prefers-reduced-motion: reduce` все переходы отключены.

## 8. Навигация

| Вкладка | Экраны |
|---|---|
| Сегодня | Скульптура и уровень, питание за день, ключевые показатели |
| Тело | Замеры, фото |
| Тренировки | Силовые |
| Питание | Дневник |
| Ещё | Советы, настройки (позже — статистика, академия) |

У каждого экрана свой адрес `#…` — он же пригодится для быстрых команд iOS.

## 9. Чек-лист перед сдачей экрана

- [ ] 390 × 844 и 375 px: нет горизонтальной прокрутки, ничего не скрыто под навигацией и safe-area
- [ ] Все зоны нажатия ≥ 44 × 44 px, между ними ≥ 8 px
- [ ] Нет эмодзи и текстовых символов вместо иконок; у кнопок-иконок есть `aria-label`
- [ ] Только токены, нет «сырых» цветов в компонентах
- [ ] Контраст текста ≥ 4,5:1 в обеих темах (проверить обе, а не одну)
- [ ] Отклик на нажатие есть и не сдвигает соседние элементы
- [ ] Видимый фокус с клавиатуры; порядок фокуса совпадает с визуальным
- [ ] `prefers-reduced-motion` учтён
- [ ] Есть пустое состояние, загрузка и ошибка
- [ ] Первый экран отвечает на один вопрос; методики и оговорки — под «подробнее»
- [ ] Ничего из запрещённого в разделе 2 («Не клон»)
