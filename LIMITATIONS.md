| Автооценка клетчатки и сахара | Доля от углеводов по категории продукта (≈ 13 категорий). Для смешанных блюд берётся источник углеводов. Это приближение, помечено «≈» |
| Ограничения по здоровью | Пометка упражнений по риск-тегам (биомеханика), а не медицинская рекомендация |
| Женская версия | Шкала уровней и силовые ориентиры — эвристика с меньшей опорой на данные. 3D: морф пола — среднее женских таргетов MakeHuman; мышечные и жировые морфы взяты мужские. Плечи и грудь связаны: при объёмном бюсте и узких плечах (например, грудь 90, плечи < 103 см) обхват плеч может не попасть в допуск — приложение пометит «вне допуска» |
| Онбординг | Значения по умолчанию нейтральные (175 см, 25 лет); без онбординга цели по весу нет |

## 3D-модель
- Это **базовый меш MakeHuman с морфами**, а не скан вашего тела: лицо, осанка, распределение мышц и жира — типовые.
- Модель стоит в A-позе. Обхват плеч в A-позе не совпадает геометрически с замером «руки вдоль тела»; калибровка подгоняет число, но форма плечевого пояса условная.
- Бицепс модели — расслабленный. Если введён только «в напряжении», берём 92 % от него (эвристика).
- Морфы MakeHuman рассчитаны на диапазон ±1. Большие обхваты (плечи, руки, предплечья у тренированного человека) достигаются **экстраполяцией** — интерфейс это пишет.
- Допуск ±2 см проверен тестом на вымышленных замерах (отклонение ≤ 0.6 см в браузере). Для очень нетипичных пропорций обхват может не попасть в допуск — тогда он помечается «вне допуска».
- Правая и левая стороны симметричны (меряется левая).
- `model-src/body.blend` создан 09.11.2026 в Blender 5.2.3 LTS скриптом `scripts/blender/make_blend.py` и проверен повторным открытием: 30 shape keys, 13 380 вершин, рост базы 173,0 см. Правки формы в Blender не обновляют `landmarks.json` — его пересоздаёт только `npm run model`.

## Хранение данных
- Данные только на устройстве. Удалили иконку / очистили данные Safari / потеряли телефон — без бэкапа данные пропадут.
- iOS может стереть данные неустановленного сайта, если он не открывался ~7 дней. Приложение просит постоянное хранилище, но iOS не гарантирует его выполнение.
- Бэкап с фото может быть большим (≈ 0.2–0.4 МБ на фото).
- Бэкап не зашифрован — храните его в своём iCloud, не пересылайте.

Альтернативы: Cloudflare Pages (в 2025–2026 в РФ были сообщения о замедлении Cloudflare — тоже проверить), Netlify, Vercel (бесплатные планы).
