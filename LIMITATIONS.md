| Ограничения по здоровью | Пометка упражнений по риск-тегам (биомеханика), а не медицинская рекомендация |
| Женская версия | Шкала уровней и силовые ориентиры — эвристика с меньшей опорой на данные. 3D: морф пола — среднее женских таргетов MakeHuman; мышечные и жировые морфы взяты мужские. Плечи и грудь связаны: при объёмном бюсте и узких плечах (например, грудь 90, плечи < 103 см) обхват плеч может не попасть в допуск — приложение пометит «вне допуска» |
| Онбординг | Значения по умолчанию нейтральные (175 см, 25 лет); без онбординга цели по весу нет |

## Прогноз и рельеф (11.11.2026)
| Место | Ограничение |
|---|---|
| Скорость набора и потолок | Эвристики (Casey Butt / FFMI 25, 1–2,5 кг сухой массы в год при стаже 4+ лет); индивидуальный разброс большой |
| Внешний вид «накачанной» модели | MakeHuman — типовой меш: рельеф мышц условный. Морфы растягиваются максимум до 1,3 (дальше появляются вздутия), поэтому очень большие бёдра и предплечья на «потолке» могут быть помечены «вне допуска» |
| Мини-отчёт | Цели по обхватам — модель «Эстетика» (FFMI ≈ 23, жир ≈ 10 %, плечи ≈ 1,6 × талия) — эвристика; упражнения — примеры, отфильтрованные по флагам здоровья, а не персональная программа |
| Пропорции Ривза и потенциал Casey Butt | Ориентиры культуристов (грудь ≈ 148 % таза, бицепс ≈ 252 % запястья — выше натурального потенциала многих); для эстетичной цели не используются |
| Поза модели | A-поза (руки в стороны): у меша нет скелета, опустить руки морфами нельзя |

## 3D-модель
- Это **базовый меш MakeHuman с морфами**, а не скан вашего тела: лицо, осанка, распределение мышц и жира — типовые.
- Модель стоит в A-позе. Обхват плеч в A-позе не совпадает геометрически с замером «руки вдоль тела»; калибровка подгоняет число, но форма плечевого пояса условная.
- Бицепс модели — расслабленный. Если введён только «в напряжении», берём 92 % от него (эвристика).
- Морфы MakeHuman рассчитаны на диапазон ±1. Большие обхваты (плечи, руки, предплечья у тренированного человека) достигаются **экстраполяцией** — интерфейс это пишет.
- Допуск ±2 см проверен тестом на вымышленных замерах (отклонение ≤ 0.6 см в браузере). Для очень нетипичных пропорций обхват может не попасть в допуск — тогда он помечается «вне допуска».
- Правая и левая стороны симметричны (меряется левая).
- `model-src/body.blend` создан 09.11.2026 в Blender 5.2.3 LTS скриптом `scripts/blender/make_blend.py` и проверен повторным открытием: 30 shape keys, 13 380 вершин, рост базы 173,0 см. Правки формы в Blender не обновляют `landmarks.json` — его пересоздаёт только `npm run model`.

## Хранение данных
- Данные только на устройстве. Удалили иконку / очистили данные Safari / потеряли телефон — без бэкапа данные пропадут.
- iOS может стереть данные неустановленного сайта, если он не открывался ~7 дней. Приложение просит постоянное хранилище, но iOS не гарантирует его выполнение.
- Бэкап с фото может быть большим (≈ 0.2–0.4 МБ на фото).
- Бэкап не зашифрован — храните его в своём iCloud, не пересылайте.

## Внешние сервисы
- **Open Food Facts**: поиск по названию 09.11.2026 работал с перебоями — сервис отдавал 503 без CORS-заголовка (вероятно, лимит частоты поиска). Тогда приложение пишет ошибку и предлагает ручной ввод. Поиск по штрихкоду работал. `search.openfoodfacts.org` не используется: браузер блокирует его по CORS.
- Данные OFF вносят пользователи — проверяйте по этикетке.
- **Хостинг**: GitHub Pages открывался с ноутбука разработки 09.11.2026. Из России без VPN, особенно с мобильного интернета, **не проверено**. Если не откроется: установленное приложение работает офлайн, интернет нужен только для обновлений. Альтернативы: Cloudflare Pages (в 2025–2026 в РФ были сообщения о замедлении Cloudflare — тоже проверить), Netlify, Vercel (бесплатные планы).
- Push-уведомлений нет: на iOS им нужен сервер. Вместо них — календарь `.ics`.

| Генератор программ | Объём, частота, повторы и отдых опираются на исследования; раскладка по дням, выбор упражнений, число подходов по стажу и оценка длительности — эвристики. Это не персональная программа от тренера |
| Ограничения по здоровью в программе | Упражнения с отмеченным риском исключаются по тегам биомеханики. Если замены нет, движение пропускается с пояснением. Это не медицинская рекомендация |
| Каталог и импорт | «Bench Press (Barbell)» из импорта и «Жим штанги лёжа» из каталога — разные упражнения в рекордах и «прошлом результате». Объём по мышцам и баллы силы считаются верно |
| Планки | В поле «повторы» вводятся секунды |
| Сканер штрихкода | Распознаёт EAN-13, EAN-8, UPC-A. Нужны камера и сеть (поиск в Open Food Facts). Товара может не быть в базе |
| «Спросить ИИ» | Оценка языковой модели, а не измерение: ошибка в десятки процентов — обычное дело. Приложение сверяет калории с БЖУ и помечает записи «оценка ИИ», но проверить вес порции не может |
| Вода | Цель задаёт пользователь; единой нормы приложение не предлагает |
| Сон и шаги | Прямого доступа к «Здоровью» у веб-приложения нет. Данные приходят текстом из Быстрой команды или вводятся вручную. Ночь относится к дню пробуждения |
| Совет про сон | Источник — обзор (Knowles 2018); порог 7 часов — общий ориентир, а не вывод этого обзора. Помечено «есть неопределённость» |
| Статистика | Средние питания считаются по дням с записями, а не по всем дням периода. Серия дней учитывает только ваши записи (замер, еда, тренировка), импортированные шаги её не продлевают |
| Отчёт PDF | Делается печатью браузера; вид зависит от браузера и принтера |
| Быстрые команды и Siri | Команда «Открыть URL» может открыть адрес в Safari, а не в установленном приложении. У них раздельные данные: в Safari будет пустой «Канон». Проверьте на одной команде, прежде чем пользоваться |
| Академия | Пересказ выводов исследований из базы знаний; не заменяет врача или тренера |
